Norlay Link Checker

Norlay Link Checker sends the link you have copied to Google Gemini, which explains what the address appears to be. The add-on never opens the link.

First time setup

  1. Get a free API key at https://aistudio.google.com/apikey.
  2. Open the NVDA menu, then Preferences, then Settings.
  3. Choose Norlay Link Checker in the list of categories.
  4. Paste the key and press OK. The key is encrypted before it is saved.

You can press Test the key to send one request and confirm that it works. The result appears in a small dialog with a Close button. That request uses a little of your free quota.

How to use it

  1. Copy a link from an email, a document, a chat or a web page.
  2. Press NVDA+Control+Shift+L, or open the NVDA menu, then Tools, then Explain link in clipboard.
  3. The explanation appears in a read-only text field. Move through it with the arrow keys, select with Shift plus the arrow keys, and press Escape or the Close button to close the window.
  4. Press NVDA+Alt+Shift+L to hear the explanation without opening a window.

You can change both shortcuts in NVDA's Input Gestures dialog, under Norlay Link Checker.

What the explanation contains

  • What the site or organisation appears to be.
  • What the path and query suggest the link is for, such as a login page or a download.
  • Anything that deserves caution, such as a lookalike name or an unexpected subdomain.

Every answer ends with the sentence: This explains the address. It is not a safety check.

Choosing a model

The default is Gemini 3.5 Flash-Lite. It is free, fast, and uses very little of the free allowance. Gemini 3.8 Flash gives better answers but its free daily limit is much smaller, so it runs out quickly.

To save quota, the add-on sends one short request per address, keeps the last 32 answers in memory, never resends history, and can leave out the query string if you turn that option off in settings.

What it cannot do

If the clipboard holds ordinary text or a file name, the add-on says that it is not a link and sends nothing. If it holds a file copied from File Explorer, it says so, and an image or another non-text format is reported the same way.

Gemini only sees the text of the address. It has not opened the page, so it cannot know what the page contains, whether it is online, or where a shortened link goes. It can be wrong or overconfident.

The explanation is not a virus scan and not a safety verdict. Be careful before you type a password or payment details anywhere.

Privacy

Nothing is sent until you press the shortcut, and the first time you are asked to confirm. The request goes only to generativelanguage.googleapis.com, the Google Gemini API. Norlay runs no server and never receives the address.

Only the address and a few short facts already worked out on your computer are sent. The page itself is never fetched, opened or resolved. The address is not written to the NVDA log or to disk, and the last answers are kept in memory only.

The add-on only reads the clipboard when you run the command, and it never writes to the clipboard. Windows clipboard history may still keep a copy of anything you copy; that is a Windows feature outside this add-on's control.

Requirements

NVDA 2026.1 or later on Windows 11, an internet connection when checking a link, and a free Gemini API key. Without a key or a connection the add-on cannot produce an explanation.
